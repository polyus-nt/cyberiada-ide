Все десять карточек модуля 9 синхронизированы с `task_fixes2.zip` от 10.11.2026: Markdown и иллюстрации перенесены без изменений, строки списка соответствуют архиву. Версии повышены относительно текущего каталога: до 3 у девяти задач и до 4 у «Двух половинок»; более старые номера из архива не используются. Входы испытаний и кодовые слова сохранены.

В «Двух каналах сразу» условие и проверка соответствуют [документу мастер-классов «Как КиберМишка принимает байты»](https://docs.google.com/document/d/1NDQe1KADYidXb2zSpJlrhIFGoHlq8Ify/edit): первый ИК-байт пары сразу меняет картинку, второй сразу меняет цвет глаз. Акустический ноль гасит оба выхода, сохраняя место в паре. Если он пришёл между половинками, следующий байт цвета меняет только глаза, а матрица остаётся пустой. Регрессионные проверки учитывают показ каждой половинки, сохранение другого выхода и порядок байтов с одинаковым временем. Все десять эталонов из архива проходят все 27 испытаний текущего каталога.

Первоначальные запросы для иллюстраций модулей 8–9 сохранены в [module-task-image-prompts.json](module-task-image-prompts.json); для заменённых картинок они описывают прежние версии. Проверки авторских правил:

```sh
python3 -m unittest discover -s tests -p test_module_task_checkers.py
npx vitest run src/main/tasks.test.ts src/common/tasks.test.ts
npm run typecheck
```

Python-тесты проверяют временные границы, паузы между одинаковыми знаками, границы пар, немедленный показ каждой части ИК-открытки, сохранение места в паре после акустического нуля, полный сброс двух половинок и повторные случайные выборы. Они не требуют установленного интерпретатора или сторонних Python-библиотек.
