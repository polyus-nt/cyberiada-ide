# Кодовый замок

Ночной люк станции заперт. Дежурный знает код, но передаёт его по внутренней акустической линии, где слышны и другие служебные сообщения. Мишка должен узнать три нужных байта подряд и открыть проход, не реагируя на случайные совпадения.

![Мишка открывает межотсечный люк](illustration.webp)

Код замка — **3, 1, 4**, полученные подряд **по акустике**. Сразу после запуска оба глаза красные, живот погашен. Как только получен полный код, зажгите оба глаза **зелёным**, а на животе покажите **улыбку**. Замок остаётся открытым до конца запуска.

Неверный байт прерывает незавершённый код. При этом байт **3** может сразу стать началом новой попытки. Байты по ИК не влияют на замок и не прерывают акустическую последовательность.

На последовательности **3, 3, 1, 4** люк откроется, а на **3, 1, 3, 4** — нет. Для первого пробного запуска подайте код 3, 1, 4 по акустике в моменты **1, 2 и 3 секунды**.
