# Кодовый замок

На ночь люк между отсеками «Орбиты-7» запирают. Дежурный передаёт код от люка по акустике, и по этой же линии идут другие служебные сообщения. Мишка должен открыть люк, только когда три нужных байта пришли подряд. Если нужный байт встретился случайно, люк остаётся запертым.

![Мишка открывает люк между отсеками](illustration.webp)

Код замка - три байта **3, 1, 4**, которые приходят по акустике подряд. Сразу после запуска оба глаза красные, матрица выключена. Как только пришёл весь код, оба глаза загораются **зелёным**, а на матрице появляется **«Улыбка»**. Люк остаётся открытым до конца запуска.

Если посреди кода пришёл неверный байт, Мишка начинает принимать код заново. Если этот неверный байт - **3**, то с него сразу начинается новый код. Байты по ИК не влияют на замок и не прерывают код.

Например, на байтах **3, 3, 1, 4** люк откроется, а на **3, 1, 3, 4** останется запертым.
