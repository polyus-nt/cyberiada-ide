# Каждый байт

Внутри станции проверяют новую акустическую связь. Передатчик посылает короткие пакеты звуком, а Мишка должен подтвердить приём каждого из них. Пока расшифровывать сообщения не требуется: связисту важно увидеть, что ни один пакет не пропал.

![Мишка слушает акустический передатчик](illustration.webp)

При **каждом байте по акустике** выбирайте случайное число от **1 до 5** и зажигайте оба глаза:

| Случайное число | Цвет |
|---|---|
| 1 | Красный |
| 2 | Зелёный |
| 3 | Голубой |
| 4 | Жёлтый |
| 5 | Белый |

Значение входного байта не влияет на выбор. Даже два одинаковых байта подряд требуют двух новых выборов; случайные цвета при этом могут совпасть. Выбранный цвет сохраняется до следующего акустического байта. До первого байта глаза погашены, живот всегда погашен. Байты по ИК пропускайте.

Для пробного запуска подайте по акустике **10, 200, 10** в моменты **1, 2 и 3 секунды**. Диапазон генератора — **[1; 6)**. После генерации для выбора по условию можно вызвать «Своё событие».
