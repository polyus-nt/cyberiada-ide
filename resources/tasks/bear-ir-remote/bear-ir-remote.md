# ИК-пульт

В тесной радиорубке станции появился новый пульт. Он передаёт команды инфракрасным светом, чтобы не занимать акустическую линию. Мишка будет показывать выбранный режим глазами и пропускать всё, что пульт отправил другим устройствам.

![Мишка принимает команды ИК-пульта](illustration.webp)

Каждая команда — **один байт по ИК**:

| Байт | Оба глаза |
|---|---|
| 0 | Погасить |
| 1 | Красные |
| 2 | Зелёные |
| 3 | Голубые |

Остальные значения **не меняют цвет**. До первой подходящей команды глаза погашены. Живот всегда погашен. Любые байты по акустике пропускайте.

Для пробы подайте по ИК **2, 9, 1, 0** в моменты **1, 2, 3 и 4 секунды**. Глаза станут зелёными, останутся зелёными, станут красными и погаснут. Акустический байт 2 не должен снова включить их.
