# ИК-пульт

В радиорубке «Орбиты-7» появился новый пульт. Он передаёт команды инфракрасным светом, чтобы не занимать акустическую линию. Мишка показывает глазами выбранный режим и пропускает команды для других устройств.

![Мишка принимает команды ИК-пульта](illustration.webp)

Каждая команда - один байт по ИК:

| Байт | Оба глаза |
|---|---|
| 0 | Погашены |
| 1 | Красные |
| 2 | Зелёные |
| 3 | Циановые |

Другие байты цвет глаз не меняют. До первой команды из таблицы глаза погашены, матрица всё время выключена. Байты по акустике пропускайте.

В первом тесте по ИК приходят байты 2, 9, 1 и 0 на отметках 1, 2, 3 и 4 с. Глаза становятся зелёными, остаются зелёными, становятся красными и гаснут.
