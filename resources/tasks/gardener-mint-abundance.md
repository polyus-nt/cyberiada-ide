# Мятное изобилие

Роботу-садовнику необходимо засеять **всё поле мятой**, кроме тех клеток, в которых уже что-то растёт.

## Условия

- Поле прямоугольное; его размер заранее неизвестен.
- Робот начинает в клетке с координатами **(0; 0)** и направлен **на юг**.
- По краям поля установлены непроходимые внешние перегородки.
- В некоторых клетках уже могут быть посажены другие растения. Проходить через такие клетки можно, но высаживать в них мяту запрещено.

## Задание

Создайте диаграмму состояний, по которой робот:

- обходит всё поле, переходя только туда, куда можно пройти;
- в каждой свободной клетке высаживает **мяту**;
- не изменяет клетки с уже посаженными растениями;
- завершает работу, когда все свободные клетки обработаны.

Итоговая позиция и направление робота не проверяются.
