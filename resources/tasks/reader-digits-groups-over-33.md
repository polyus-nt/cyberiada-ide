# Строчник и числа

Строчник получает на вход строку, которая состоит из **цифр** и **дефисов** (`-`). Он читает символы один за другим слева направо и может подавать импульс на выход **А**.

Постройте диаграмму работы строчника, чтобы она:

- складывала значения цифр, идущих подряд, то есть между дефисами;
- после каждого дефиса обнуляла сумму и начинала новый подсчёт;
- подавала **один импульс на выход А**, если сумма цифр в какой-либо группе стала больше 33;
- после этого продолжала обработку оставшейся строки.

## Пример 1

Входная строка: `5-9999`

- `5` → сумма = 5;
- `9999` → сумма = 36 → строчник подаёт импульс на **А**.

## Пример 2

Входная строка: `10-20-4`

- `10` → сумма = `1 + 0 = 1`;
- `20` → сумма = `2 + 0 = 2`;
- `4` → сумма = 4.

Ни в одной группе сумма не превышает 33, поэтому импульса нет.
