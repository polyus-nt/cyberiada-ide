# Строчник: буквы А, Б и В

Исполнитель «Строчник» получает на вход строку, состоящую из букв русского алфавита. Ваша задача — построить диаграмму работы строчника, который подаёт сигналы на выходы **А**, **Б** и **В**.

Требования к диаграмме:

- Если во входной строке встречается буква **А**, строчник подаёт сигнал на выход **А**.
- Если встречается буква **Б** — сигнал на выход **Б**.
- Если встречается буква **В** — сигнал на выход **В**.
- Для остальных букв сигналы не подаются.

## Пример

Входная строка: `ВАББГ`

Ожидаемые сигналы:

- При появлении `В` — сигнал на выход **В**
- При появлении `А` — сигнал на выход **А**
- При появлении `Б` — сигнал на выход **Б** (дважды)
- Буква `Г` игнорируется

Для того, чтобы сдать решение, создайте диаграмму по условию и сохраните её в файл. Затем откройте этот файл в блокноте (или другом текстовом редакторе), скопируйте **всё** содержимое файла и вставьте его в переменную `state_machine` в поле ввода решения. Больше никаких действий с текстом не требуется, иначе проверочная система может не принять вашу диаграмму.
